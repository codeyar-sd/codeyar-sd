مفهوم کلاس و شیء

کلاس، الگوی ساخت اشیاست. هر شیء می‌تواند ویژگی و رفتار داشته باشد.

class Student:
    def __init__(self, name, grade):
        self.name = name
        self.grade = grade

    def introduce(self):
        return f"{self.name}: {self.grade}"

student = Student("Sara", 19)
print(student.introduce())
