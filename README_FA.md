# CodeYar SD AI Academy — MVP 1.1

طراح: **sahar dinar**

## چه چیز تازه‌ای اضافه شده؟
- دکمه «اجرای واقعی Python» با مفسر Pyodide داخل مرورگر؛ کد Python به‌جای شبیه‌سازی ساده، واقعاً در محیط مرورگر اجرا می‌شود.
- اجرای آموزشی محدود قبلی همچنان برای حالت آفلاین حفظ شده است.
- نسخه کش Service Worker به‌روزرسانی شده تا مرورگر فایل‌های جدید را دریافت کند.

## اجرای محلی
در پوشه پروژه اجرا کنید:
```bash
python -m http.server 8000
```
سپس `http://localhost:8000` را باز کنید. اجرای واقعی Python در اولین استفاده به اینترنت نیاز دارد تا Pyodide بارگیری شود؛ پس از آن در همان نشست مرورگر معمولاً دوباره بارگیری لازم نیست. اجرای آفلاین کامل Pyodide هنوز در این بسته قرار ندارد.

## انتشار رایگان با GitHub Pages
1. وارد GitHub شوید و یک repository جدید بسازید.
2. تمام فایل‌های داخل این پوشه را (نه فقط فایل ZIP) در ریشه repository بارگذاری کنید.
3. از **Settings → Pages** بخش **Build and deployment** را روی **Deploy from a branch** بگذارید.
4. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.
5. پس از آماده‌شدن انتشار، GitHub نشانی وب‌سایت را در همان صفحه نمایش می‌دهد.
6. نشانی HTTPS را در Chrome باز کنید و از منو گزینه **Install app** یا **Add to Home screen** را بزنید.

## نصب روی Android
این پروژه یک PWA است و می‌تواند از مرورگر به صفحه اصلی افزوده شود. این بسته **APK مستقل یا امضاشده نیست**.

## محدودیت‌های شفاف
- Pyodide کد Python را در مرورگر اجرا می‌کند، اما همه بسته‌های Python یا قابلیت‌های وابسته به سیستم‌عامل در WebAssembly در دسترس نیستند.
- Pyodide برای بارگیری اولیه به اینترنت نیاز دارد؛ فایل‌های runtime بزرگ آن در این ZIP گنجانده نشده‌اند.
- اجرای واقعی Django روی سرور فراهم نیست؛ کدها و آموزش‌های Django نمونه‌های آموزشی‌اند و برای اجرای پروژه واقعی به backend نیاز است.
- معلم آفلاین از دانش‌نامه محلی محدود استفاده می‌کند و مدل زبانی کامل نیست.
- داده‌ها روی همان دستگاه ذخیره می‌شوند؛ حساب کاربری، همگام‌سازی ابری، PostgreSQL، داشبورد مدرسه، اشتراک و بازار هنوز پیاده‌سازی نشده‌اند.

## ایمنی و استفاده آموزشی
کد در مرورگر اجرا می‌شود و نباید برای کدهای ناشناس یا حساس، محیطی کاملاً ایزوله و حرفه‌ای فرض شود. برای اجرای پروژه‌های کاربران روی سرور، از containerهای جداگانه با محدودیت منابع و کنترل دسترسی استفاده کنید.
